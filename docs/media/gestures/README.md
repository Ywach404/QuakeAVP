# Control diagrams

`manifest.json` is the single list of what every control does; the SVGs beside
it are one diagram per hand gesture. The README's **Controls** tables mirror
the same entries by hand -- nothing generates them, so a blurb edited here
needs the same edit there. The diagrams are generated by
`tools/gestures/make-gestures.py` from one shared hand geometry — edit the
script and re-run it rather than editing an SVG, or the set drifts apart — but
the SVGs are committed artifacts and nothing builds them at build time. Each
entry carries the file and line that actually implements the binding, so a
control that moves in the code is caught here rather than in a bug report.

## Schema

`manifest.json` is `{ "version", "handedness", "controls": [ … ] }`. Each
control is:

| field | meaning |
| --- | --- |
| `id` | stable key, `hands-…` or `sense-…`; also the SVG's basename |
| `input` | `"hands"` (bare-hand tracking) or `"sense"` (PSVR2 Sense pair) |
| `hand` | `"off"`, `"gun"`, `"both"`, `"either"` for hands; `"left"`, `"right"`, `"either"` for Sense |
| `fingers` | hands only: the fingers or pose the gesture uses |
| `control` | Sense only: the physical control |
| `motion` | what you do with it — `hold`, `pinch`, `press`, `whip sideways`, … |
| `action` | the short label, as the README table shows it |
| `blurb` | one or two plain sentences, as the README table shows them |
| `diagram` | the SVG filename, or `null` for a control with no diagram |
| `source` | `path:line` for every place the binding is actually decided |

Handedness: diagrams are drawn for the default right-handed setting, so the off
hand is the left and the gun hand is the right. Comfort swaps both.

## Drawing conventions

Stroke-only line art, no fills, round caps and joins. Four classes carry
everything: `.ln` the hand silhouette, `.hi` the active pinch pair and its
contact point, `.arw` motion, `.gst` context (ground, anchors, destinations).
Colours live in a `prefers-color-scheme` block so one file reads on a light and
a dark page — which is what an `<img>` in a README needs. The hand is defined
once, as the left hand seen from the back; the right hand is that same path
mirrored. A pinch folds the fingers between the thumb and its target, so the
thumb never crosses a finger it is not touching.

## Not here yet

A single composite poster — every gesture on one sheet with leader lines, the
way a headset's quick-reference card does it — is future work. The per-gesture
diagrams and the manifest are the pieces it would be assembled from.

`manifest.json` is also meant to seed a remap UI: it is the list of controls a
settings screen would have to show, in a form that does not need the gesture
code read first.
